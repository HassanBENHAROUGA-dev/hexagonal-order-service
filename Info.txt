📦 MATRICE DES DÉPENDANCES (Qui importe quoi ?)
La règle absolue : L'extérieur dépend de l'intérieur. Jamais l'inverse.

[4. INFRASTRUCTURE]
com.company.shop.order.infrastructure
 ├── Peut importer : TOUS LES PACKAGES EN DESSOUS
 │    ├─> adapter.* (Pour brancher les Beans Spring)
 │    ├─> application.* (Pour instancier le Use Case)
 │    └─> domain.* (Pour la configuration globale si besoin)
 └── Interdiction : Aucune, c'est la couche d'assemblage suprême.

        │
        ▼ (Injection de dépendances)

[3. ADAPTERS]
com.company.shop.order.adapter
 ├── adapter.in.rest
 │    ├─> Peut importer : application.port.in (ManageOrderUseCase)
 │    ├─> Peut importer : application.command (DTOs)
 │    └─> Interdiction : De parler directement au Domaine.
 │
 ├── adapter.out.persistence
 │    ├─> Peut importer : domain.repository (Pour implémenter le Port)
 │    ├─> Peut importer : domain.aggregate & domain.valueobject (Pour le Mapping)
 │    └─> Interdiction : De parler à application.* ou aux autres adapters.
 │
 └── adapter.out.* (messaging, payment)
      ├─> Peut importer : application.port.out (Pour implémenter les Ports)
      └─> Peut importer : domain.event & domain.valueobject

        │
        ▼ (Contrats et Orchestration)

[2. APPLICATION]
com.company.shop.order.application
 ├── Peut importer : UNIQUEMENT LE DOMAINE
 │    ├─> domain.aggregate (Pour appeler order.confirm())
 │    ├─> domain.repository (Pour charger l'Order)
 │    └─> domain.valueobject (Pour manipuler les IDs et les montants)
 └── Interdiction : D'importer des adapters ou de l'infrastructure. Zéro Spring ici.

        │
        ▼ (Cœur Métier Pur)
